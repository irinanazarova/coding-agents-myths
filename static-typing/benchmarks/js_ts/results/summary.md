## Agent behaviour from the 559 trajectories

mini-SWE-agent gives the model one bash tool. No type checker or language server is wired in; the model runs `tsc` only if it chooses to. The harness runs tests through jest, vitest, mocha or karma with Babel, esbuild or SWC transforms, none of which type-check, so a type error in a TypeScript patch does not by itself fail a task.
